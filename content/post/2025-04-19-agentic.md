Starting from around the year 2022, we see the big power of language models and other generative models. So the generative AI, people have seen a superior capability of generating content like text and images. They are much better than the generative techniques 20 years ago or 15 years ago. Apparently, these days the new technique has passed  the bar that we can think about more creative applications, higher level of AI capabilities. And so what's the next? What are the best way to leverage these generative AI techniques? 

In this article, I will talk about two main problems: 
- Agentic AI Frameworks: What are future AI applications like? 
- AutoGen: How do we empower every developer to build them?

Let's start with the first question. 

## What are future AI applications like?


Starting from 2023, researchers start to think about that question and made a lot of technique bets along the way. The most important bet would be that they think the future AI applications can be agentic. And the agents can be a new way for human to interact with the digital world and help us execute more complex tasks on behalf of a human and get to higher and higher level of complexity. And at that time, many people still  have doubts about whether agentics AI can be a viable notion. But as time goes by, we are seeing more and more confirmation and evidence, including earlier 2024, there's an article published by Berkeley talking about how we are observing more and more AI resulting shifting from using a simple langauge model to building compound AI systems (@guptaShiftModelsCompound). So that's one of the similar observations and technical bets. 

![](https://bair.berkeley.edu/static/blog/compound-ai-systems/compound-ai-systems.png)


### Examples of Agentic AI 

So if we think about the examples of agentic AI, you'll notice that building AI agents like personal assistants, 
- Personal assistants 
- Autonomous robots 
- Gaming agents

There's the notion of agent AI is not new. But what's new is that with the power of the new generative AI techniques and the language models. For example, we are able to build some of the old agentic applications much easier and much more capable. And the same time, we are also seeing some very new novel agent applications that go beyond the imagination we had before, such as some science agents that can do science discovery automatically, web agents that can automate some web browsing and web automation tasks, and also software agents that can build even software from begining to the scratch. 

### Key Benfits of Agentic AI

In future, we may build the software in a totally different way. So to summarize the key benefits of agentic AI,

1. AI is able to use more natural interface to talk with humans. So you can tell them what you want exactly. In this case, we just tell them we want to build a website with contain requirements. And then you can iterate over the natural language. 
2. By giving the agents more capability, they are able to operate and finish more complex tasks with minimal human supervision. So that has tremendous value in terms of automation.
3.  Agentic AI can be also a very useful software architecture to enable us to build software in a totally different way so that you can have multiple agents working with each other and to finish much more tasks in a recursive way. 

```
- Useful Interface 
  - Natural interaction with human agency 
- Strong Capability 
  - Operate with minimal human itervention 
- Useful Architecture 
  - Intuitive programming paradigm 
```

I will use a simple example to go over this benefits. So let's look at one particular example application about solving some supply chain optimization on cloud.

It allows users like coffee shop owners to answer questions like, **what if we change the shipping constraints? How would that affect my operating cost?**

This is a difficult question. They can't get answers from ChatGPT because the AI needs to understand the user's specific data constraints and even some optimization tools to be able to understand the question and get the answer. 

But in this case, they used AutoGen to build three agents that can solve this question very nicely. The three agents are commander, writer, and safeguard. So let's see how that works.
